OPTIONAL CUSTOM CUT-OUTS
------------------------
The app ships with original vector emblems (a straw-hat-and-crown for Luffy mode,
a skull-and-sabres for Blackbeard mode). To use your own character art instead,
drop transparent PNGs here with EXACTLY these names:

    luffy.png        shown in "Luffy" mode
    blackbeard.png   shown in "Blackbeard" mode

Tall images (roughly 2:3) with a transparent background look best.
If a file is missing, the built-in emblem is used automatically.
